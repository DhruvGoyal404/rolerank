# Security

Please report vulnerabilities through GitHub's private vulnerability reporting:
the **Security** tab of this repository, then **Report a vulnerability**. Don't open a
public issue.

Resumes are personal data, so reports about authentication, file upload, access
control or deletion matter most. The threat model is in
[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).

This is a student project with no bug bounty. You'll get a reply as soon as possible.
